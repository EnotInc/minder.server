# minser.server

Для запуска сервера дополнительно необходимо добавить `.env` файл (описание которого есть в [доках](https://github.com/EnotInc/MinderDocs)) в корень проекта, и файл `serviseAccountKey.json` в папку `sevices/notificatoins/`. Нужен он для подключения firebase, и как его получить можно почитать [на их сайте](https://firebase.google.com)
